PLANER V55 — TAPETENWECHSEL

Basis: v53.1 Spotify, ausdrücklich OHNE die dynamischen Raumanimationen aus v54.

Funktionen
----------
- Neue Option "Tapetenwechsel" in der Schublade.
- "Studienzimmer" ist immer vorhanden, nicht löschbar und als Standard auswählbar.
- Beliebig viele eigene Tapeten.
- Foto aus Galerie/Mediathek oder direkt per Kamera.
- Name für jede Tapete.
- Vollbild-Editor: Tippen auf das Foto -> unsichtbaren Link platzieren.
- Ziele: Bücher, Planer, Träume, Tage, Philosophie, Physik, Notizen, Filme,
  Wikipedia, Nachrichten, Musik, Schach, Menü, Zurück oder Neues Foto.
- "Neues Foto" erzeugt eine weitere verknüpfte Szene; dort können wieder
  Apps oder weitere Fotos verknüpft werden.
- Hauptfoto benötigt zwingend mindestens einen "Menü"-Link.
- Jedes zusätzliche Foto benötigt mindestens "Zurück" oder "Menü".
- Herz in der Tapetenliste aktiviert die Overall-Oberfläche.
- Eigene Tapeten können aktiviert, bearbeitet, umbenannt, dupliziert,
  exportiert und gelöscht werden.
- Import eigener .planerwallpaper-Dateien.
- Fotos liegen lokal in IndexedDB und werden vor dem Speichern auf max.
  2400 px Kantenlänge komprimiert.
- Keine Tapeten- oder Raumanimationen.

Hinweis
-------
Eigene Tapeten sind lokal auf dem jeweiligen Gerät gespeichert. Export/Import
dient zum Backup und Transfer auf andere Geräte.
